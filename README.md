# 🎉 EduSync - Production Ready

AI-powered peer learning platform with real-time chat, matching algorithm, and AI tutor.

## 🚀 Quick Start (2 minutes)

```bash
# 1. Install dependencies
cd edusync/backend && npm install
cd ../edusync-next && npm install

# 2. Start servers
# Terminal 1: npm run dev (from backend)
# Terminal 2: npm run dev (from edusync-next)

# 3. Open browser
http://localhost:3000
```
